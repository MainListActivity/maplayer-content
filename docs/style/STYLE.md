# 风格圣经 · 《静默信标》线（所有原画的硬规范）

> 验收口径只有一句：**像不像 style-bible**。像=过，不像=退。本文件是"怎么像"。

## 0. 基线资产（唯一参照系）

`public/assets/style-bible/` 存放老板选定的风格定稿。任何角色/场景/道具任务，
动手前先看基线，交付时附一张与基线同场景的对比帧。没有基线时不许开工——
先走「风格方向」任务出候选，老板选定后它才存在。

## 1. 线稿

| 项 | 规范 |
|---|---|
| 墨色 | 主描边 `#1d1826`；暗部内描边可用 `#3a2f4a`；禁纯黑 `#000` |
| 线宽 | 外轮廓 4~5px、服装/道具 3~4px、五官 2.5~3.5px（以 viewBox 计） |
| 线端 | `stroke-linecap="round"`、`stroke-linejoin="round"` 必备 |
| 手绘感 | 所有描边组套 `filter="url(#rq)"`（共享 defs，scale 3~5） |
| 禁 | 直线段拼圆、stroke<2.5（渲染后糊）、无描边色块裸奔（发光体除外） |

## 2. 上色（赛璐璐三阶）

每块固有色 = 底色 + 阴影色（明度 -20%、饱和度 +5%）+ 可选高光（明度 +15%）。
- 阴影形状是**有边界的色块**，不是渐变；位置跟随统一光源（默认左上 45°）
- 渐变只允许用于：发光体、全息/能量、大气远景
- 每集色板 `public/episodes/<ep>/palette.json`，lint 按容差校色，越界报警

## 3. 角色比例（模板强制）

用 `public/assets/templates/character-front.svg` 起稿，不改骨架：
- 头:身高 = 1:4（青年）/ 1:3.5（Q 版）；肩宽 ≈ 1.5 头宽
- 五官定位线：眼在头高 45~55% 处，两眼距 ≈ 1 眼宽；鼻在 65%；嘴在 75~80%
- 图层顺序：后发→身体→颈→脸→五官→前发→饰品；动画组 `eyes/mouth/mouth-open` 在五官层

## 4. 场景

- 地平线统一在画面 40~60% 高度；一点透视灭点入画面中心 1/3 区
- 大气透视：远景明度 +15% 饱和度 -25%，近景反之
- 同题材共用光色：舰桥冷蓝 `#16233a` 环境 + `#ffd27a` 琥珀光点缀；警报 `#e04a4a`

## 5. 道具/服化道

- 与角色同一墨色线宽体系；屏幕/全息用 `#3aa6a0`~`#7fd8e8` 族 + 内发光
- 辨识度>写实度：剪影要能一眼认出用途

## 6. 机器卡口（validate --art）

- SVG 必须有 `viewBox`；禁 `<image>` 位图嵌入
- 角色必须含 `#eyes`(`#eye-l/#eye-r`)、`#mouth` 或 `#mouth-open`
- 描边宽度落在 §1 区间；主色落进 palette 容差
- 复杂度下限：角色 ≥30 形状元素，场景 ≥60（过少=火柴人级，直接退回）
- `filter id="rq*"` 手绘滤镜存在（警告级）
