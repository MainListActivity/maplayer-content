# 风格圣经 · 《静默信标》线（所有原画的硬规范）

> 验收口径只有一句：**像不像 style-bible**。像=过，不像=退。本文件是"怎么像"。

## 0. 基线资产（唯一参照系）

`public/assets/style-bible/` 存放老板选定的风格定稿。
**当前基线 = 方向 D+「原图路线」**（老板选定，见 `style-bible/STYLE-BIBLE.md`）：
插画风位图（painterly raster），暖色环境灯 + 冷色屏幕光的混合照明，
非矢量线稿风。任何角色/场景/道具任务，动手前先看基线，交付时附对比帧。

## 1. 位图资产（基线路线，首选）

- 场景：满幅 PNG，有效分辨率 ≥1920×1080（含变焦余量宜 ≥2×）；16:9
- 角色/道具：透明底 PNG（alpha 通道必需）；角色底部中心 = 脚底站位锚点
- 派生自基线主稿（crop/补洞/抠图）时保持原笔触与光色，不得混入其他画风
- 回忆/闪回类场景：低饱和近似单色（灰度化 + 轻对比）

## 2. SVG 资产（兼容路线，次选）

仍允许的场合：动画挂点必需（口型/眨眼）、UI/示意元素、基线未覆盖的急件。
沿用原硬规范：

| 项 | 规范 |
|---|---|
| 墨色 | 主描边 `#1d1826`；暗部内描边 `#3a2f4a`；禁纯黑 `#000` |
| 线宽 | 外轮廓 4~5px、服装/道具 3~4px、五官 2.5~3.5px（以 viewBox 计） |
| 线端 | `stroke-linecap="round"`、`stroke-linejoin="round"` 必备 |
| 上色 | 赛璐璐三阶：底色 + 有边界阴影块 + 可选高光；渐变只许发光体/全息/大气 |
| 比例 | 头:身高 1:4（青年）/1:3.5（Q 版）；眼在头高 45~55%；嘴 75~80% |
| 动画组 | `#eyes`/`#eye-l/r`、`#mouth`/`#mouth-open`（位图无挂点，用脉动代替） |
| 滤镜 | `filter="url(#rq)"` 手绘抖动（scale 3~5） |
| 色板 | `public/episodes/<ep>/palette.json` 容差内 |

## 3. 场景构图（两路线通用）

- 地平线统一在画面 40~60% 高度；一点透视灭点入画面中心 1/3 区
- 舰桥基调：冷蓝环境 + 琥珀光点缀；警报 `#e04a4a`；全息 `#3aa6a0`~`#7fd8e8`
- 辨识度>写实度：道具剪影要能一眼认出用途

## 4. 机器卡口（validate --art）

- `.png`：场景 ≥1920×1080 且 ~16:9；角色/道具必须有 alpha 通道
- `.svg`：必须有 `viewBox`；禁 `<image>` 位图嵌入；角色含 `#eyes`、`#mouth` 动画组；
  线宽/复杂度/色板/滤镜按 §2 检查（基线落地后为失败级）
