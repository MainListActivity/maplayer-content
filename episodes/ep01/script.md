# 第一集《深痕拂晓》剧本（第七纪元·林拓线起笔）

题材：宏大科幻 / 纪元史诗 / 悬疑 · 2D 手绘风格 · 目标单集时长约 5 分钟（预估合计 292 秒）
依据《科幻故事续写筹备.md》终极骨架重写：彻底废止旧设定（聆汐/凛/凯恩），正式确立“大地之梦 / 地磁刻痕”四幕史诗篇章。百万字长篇节奏，从地表普通生活日常缓缓展开，直至深潜入二十八公里深地，触碰远古雷暴刻下的第一记回音。

## 核心世界观与设定档案

### 世界观三大法则
- **地质清洗律**：板块俯冲、地幔对流与数十亿年风化会彻底抹平一切人造物理残骸。无金属、无化石、无建筑废墟留存，大地从未被真正征服。
- **天地刻录律**：文明在失控崩溃爆发能量时，诱发的超极雷暴与太阳耀斑会改写古地磁场的磁畴排列，将特定瞬间以“岩石磁畴全息”的形式刻录在大地深处。
- **浮生若梦法则**：生命与文明的繁衍灭亡只是地球地质周期的微观高热。从无主宰，繁华与狂妄皆为幻梦，仅余磁电回响。

### 角色设定
- **林拓（lintuo）**：第七纪元·智人末期，第三大陆深地开发署·第七勘测局在编二级地质物理开发员（工号：M03-7749）。性格冷静克制、崇尚理性规律。长年往返深地与地表，患有轻微低频耳鸣与关节冷感症；习惯饮用高浓度苦味代咖啡。
  - *常态化着装（居家/通勤便服，variant: casual）*：洗得微发灰的深藏青色软质聚酯抓绒衫，下身宽松工装灰长裤，底纹磨损的软底步行靴；神情带着倒班特有的淡漠与轻度疲倦。
  - *作业外骨骼装（variant: exo）*：深石墨色“深潜轻压外骨骼工服”。耐高温微孔陶瓷纤维，表面哑光粗糙；双肩与腰椎咬合钛哑光外骨骼支撑导轨，胸前斜跨微型地质液压套索；领口为硬质磁吸密闭环，内嵌淡琥珀色生命体征脉冲光环；左小臂固定半柔性触控副屏，手腕戴磨损聚合物防震手套，指节带炭灰色岩石擦痕。
- **苏沫（sumo）**：林拓的伴侣，地表第三生态环城市规划局档案员。务实、温和，对林拓的工作抱有习惯性担忧，更关心生活开支与下季度休假。
  - *常态化着装（variant: default）*：浅杏色针织开衫，内衬柔软浅灰色棉质长裙，头发用不起眼的木质发簪松挽在脑后，手腕戴一块仅显示地表光照周期的指针手环。

### 场景设定
- **栖水里·卧室与客厅（habitat-room）**：北三区高密度居住塔楼72层（45㎡）。蜂巢巨碑式建筑，室内极简紧凑。窗外为鳞次栉比的悬浮轨道与阴雨连绵。
- **栖水里·阳台与落地窗（habitat-balcony）**：落地窗贴满冷雨水痕，可远眺天际线上穿破云层的“天幔吸收塔”轮廓；阳台狭窄隔间置有一盆需恒温罩维生的古老绿萝。
- **零号枢纽·候工大厅（hub-zero）**：升降深井·零号枢纽，连接地表与深地的两百米挑高庞大机械森林。成千上万工人穿梭在黄黑安全网格线上；巨大磁悬浮深井提升机吞吐重力气囊，蒸汽与机油味弥漫。
- **重力下降吊舱（descent-pod）**：下潜钢铁巨棺。蜂窝防压内壁、昏暗红色安全应急光、重力转换减震悬挂座；窗外是向下飞掠的幽深井道与岩层标尺光带。
- **莫霍浅层三号观测井（moho-station）**：地下28公里处的超深绝热球形空腔（直径120米）。四壁为灰白色耐热压复合蜂窝陶瓷板，缝隙泛着淡蓝冷却液光；中央横跨悬空钛合金检修钢桥，下方为阻隔滚烫暗红地幔的防护力场护盾；头顶盘旋巨大环形冷却进气管。
