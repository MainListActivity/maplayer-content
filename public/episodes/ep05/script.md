# 《我在》人物与动画重新设计

老板反馈旧版动画非常生硬，并明确允许人物和动画重新设计。本版本使用新画的人物、面部原画和空舰桥，建立新的 P 段候选方案。

凛走进静默的监听室。她停下，侧耳确认，抬手发出轻声询问；听到回应后把手收回，微笑点头。动作由身体的感知与回应驱动。

| 时间 | 演出 | 镜头 / 台词 |
|---|---|---|
| 0–0.60s | 重心前移，准备迈步 | 全身景，脚底入画 |
| 0.60–3.60s | 三个步行周期，支撑脚锁定；摆腿抬脚、反向摆臂 | x .22→.49，镜头缓推 |
| 3.60–5.25s | 停步缓冲，头部先侧倾，躯干稍后安定，眨眼 | 留出感知停顿 |
| 5.25–8.50s | “有人在吗？”；手臂抬起，手腕稍后落定 | 清楚的开放手势 |
| 8.50–13.00s | 接续同一姿态；保持倾听，随后收手，表情逐渐放松 | 切到更近的中景，缓推 |
| 13.00–18.083s | “我在。慢慢说。”；轻点头，眨眼，留出回应后停顿 | 字幕与配音沿用现有管线 |

新人物：青年成人比例、短棕发、琥珀色识别夹、无线电耳麦、象牙白/深青工作服、深色修身裤靴。v4 为 23 个插画部件，含四个表情头、四个口型；两只手各自独立，近侧左手有手背/窄侧/掌心三个视图。动作按 24fps 采样，双段动作使用全局连续时间，剪辑点不重启动作。

v4 根据老板“手的方向都反了”的反馈，重绘两只手，按真实原画方向重新分配左右关系。垂手时两张手背视图的拇指朝身体内侧；抬手后近侧左手经窄侧视图翻为开放掌心，收手时回到手背视图。手的视图逐帧切换，同一帧仅显示一张，避免拇指透明重影。

步态使用两骨骼 IK，支撑期脚踝目标抵消角色位移。shots 使用 gait:none 来关闭引擎默认额外抖动，步态和重心变化由本版本的部件轨道完整提供。不能将 gait:none 理解为无腿部运动。

口型由实际 MP3 的分帧 RMS 驱动开合，O 型混合是简单近似，不是语音音素识别。眨眼、重心、头部、肩/肘/腕分别有时序。环境是新绘制的空舰桥，场景与屏幕光分层、低密度微尘；不复用旧图修补/切片。

复现：`node public/episodes/ep05/_source/build.mjs` → `pnpm audio ep05`（音轨缺失或台词改变时）→ 再运行 build（烘焙真实音轨的口型）→ `pnpm validate ep05` → `pnpm render ep05 ep05-hand-fix-v4.mp4` → `pnpm frames renders/ep05-hand-fix-v4.mp4 0.25 6`。`pnpm exec tsx public/episodes/ep05/_source/check-hands.ts <绝对证据目录>` 输出 14 张固定帧和全片腕部几何检测。

说明：背景原始生成尺寸 1672×941，使用 Lanczos 重采样为 2560×1440，并非原生 2K 细节。四个 36×28 口型及 26×73 窄侧手图在 validate 有小位图警告。此候选仍是 2D 关节动画，没有完整三维转身、衣料动态、逐指运动或逐音素口型；能否达到老板对自然度的要求，以新版播放验收为准。
