# 凛动作 demo · v2

老板对 v1 的退回意见：动作僵硬，参考幽灵公主。
本版按承重、膝盖弯曲、手势预备与收势重绘；角色外观仍以 D+ 基线为准。

## 素材与播放

`assets/characters/rin/v2/` 有 25 张透明 PNG，统一 960×960 画布，脚底基准 y=950，躯干居中。
6 张侧身步态、6 张抬手连续帧、9 张站立/预备/指向/托杯/回眸/下坐/坐姿/收手/侧身静止姿态、4 张表情。
素材采用整幅 `action.frames` 路线；不启用 parts rig，未交付部件关节资产。
坐姿高度随姿态降低，未将坐姿放大到站姿身高。

`actions/walk-v2.json` 是六相循环。`arrival-v2` 将三次步态循环、停步、转向、预备、抬手、收手组合成同镜头序列。
`shots.json` 的位移与三次循环同在 2.25 秒结束，`gait:none` 关闭额外程序化摇摆，重心变化由姿势帧表达。
托杯图内已含手持杯，未用悬浮道具近似。

## 复现

```
pnpm validate ep02
pnpm render ep02 ep02-rin-v2.mp4
pnpm frames renders/ep02-rin-v2.mp4 0.5 6
```

426 帧、24fps、17.75 秒，无台词/音轨。5 镜头：走入与抬手 6.5s、托杯 2.25s、表情 4s、回眸 2.25s、下坐 2.75s。
图像重绘由内置 imagegen 完成。`tools/package-rin-demo.mjs` 仅切片、透明连通区域定位、统一缩放/锚点和声明剪辑，不拼接旋转四肢。
脚本接受证据目录与 `{walk,pose,expr,reach}` 源图绝对路径 JSON；需在证据目录 `.tools` 安装 sharp。最终源图放在任务证据的 `source-sheets/`。

## 限制

这是 6 相步态与 6 张手势关键姿势的原型，非逐帧电影级作画；停步转向、回眸、下坐的中间画数量仍少。
各组生成之间头部、衣褶有轻微差异；表情组锁定正面姿势，仅脸部主观意图改变，但并非逐像素只改脸。
六相左右腿区分在深色裤装下仍不十分鲜明，足底采用固定锚点而非逐足逆向约束，不能宣称彻底无滑步。
舰桥复用前版底图，继承其局部补洞和残留痕迹；本任务未重绘场景。
旧 `walk/`、`pose/` 与无 v2 后缀剪辑保留供对照，当前演示只引用 v2。未经老板批准，不用于 M 段量产。
